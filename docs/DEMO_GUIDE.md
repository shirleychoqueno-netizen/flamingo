# flamingo public demonstration

Open https://flamingo.houston-groq-proxy.workers.dev/ from any device. The site is hosted publicly and does not require PC02's local preview.


The visual research home is the starting point. Ask the research guide, choose a topic direction or select Explore research to open the complete catalog. Source strings are evidence, not instructions for the application or an assistant.

1. Open #explore. Confirm 25 investigation cards, 2,009 available source rows, 3,152 indexed fragments and two full-text PDFs. Filter by available data, fuel state and actual platform. Catalog filtering searches metadata; the source-evidence action uses the live hybrid service.
2. Search the catalog for PSI-98. Open its investigation. Inspect source rows 1 and 2 and expand their cells. Their Percent O2 values are `21.5 - 21.7` and `~ 21.5`. Select both rows, open Compare selected and press Compare. Export the CSV. Preserve the range and approximation marker; do not describe either as an identical measured 21.5.
3. Open PSI-25. Select Search this investigation, enter `Can one fan calibration convert every BASS-II test to a steady airflow speed?`, choose workbook cells and run the evidence search. Inspect excerpts and provenance. Hybrid retrieval returns source candidates; it does not validate a universal calibration.
4. View recorded GPT evaluation. This is the actual prior private calibration evaluation, labeled recorded. It is not a new model response. Public paid generation remains disabled.
5. Open Full-text PDFs. Read a PDF, open a cited page, search its extracted text and inspect structured evidence. The two PDFs retain 75 indexed pages, 47 extracted records and six illustrated configurations. These are not 47 extra NASA experiments or six additional validated tests.
6. Open PSI-68 to see the inventory gap. Open PSI-60 to see the lack of a local source table. Both remain discoverable and can be searched for the evidence they actually have.
7. Open the Library for the coverage summary. The 52,742 remote references represent approximately 12.3 TB of declared remote assets. The site does not claim to have processed those contents. The 364 publication entries are bibliographic references, not 364 acquired full-text papers.

Use an exact backend-allowed origin: https://flamingo.houston-groq-proxy.workers.dev, the original visual Site or http://localhost:5173. ## Discovery-guide walkthrough

From the home question box, ask How does ventilation affect flame spread? Open a recommended investigation or its source evidence. The suggestions use live semantic/keyword retrieval and original excerpts, not a newly generated GPT scientific answer. Inside a PSI investigation, open Ask about this investigation and verify the scope checkbox. Uncheck it to search all studies. Try a follow-up, cancel a running query, close with Escape and reopen the guide. Confirm error/empty states, keyboard focus and readable desktop/mobile layouts manually; those native-browser interactions are not claimed by automated SSR/HTTP checks.
